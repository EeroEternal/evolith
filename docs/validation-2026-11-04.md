# First real GPU validation, 2026-11-04

## Result

The measured optimization loop runs on real RTX 5090 hardware, including
independent correctness checks, kernel parameter search, an opt-in vLLM adapter,
real Qwen generation, and a subsequent search using Qwen-generated parameters.
**No end-to-end deployment was approved.** Microbenchmark gains are not
end-to-end gains.

## Environment

- Eight RTX 5090 GPUs, 32,607 MiB reported memory each; CUDA capability 12.0.
- NVIDIA driver 595.99.02.
- Cached vLLM image ID:
  `sha256:7a0f0fdd2771464b6976625c2b2d5dd46f566aa00fbc53eceab86ef50883da90`.
- Container Python 3.12.13, PyTorch 2.10.0+cu129, Triton 3.6.0,
  vLLM 0.19.0, Transformers 4.57.6.
- Existing Qwen3.5-27B BF16 weights, hidden size 5120, RMSNorm epsilon 1e-6.
- Single GPU for each kernel search; four GPUs for the real model.
- No network ports exposed, insecure serialization enabled, or existing
  services stopped. All Evolith containers exited and released their GPUs.

The tested two-GPU model initialization failed its KV-cache capacity check
after profiling. Four GPUs left approximately 11.9 GiB of cache budget per
worker. This is a tested configuration, not a minimum-memory guarantee.

## Full-model verification

Evidence: `results/20261104T121513Z-50cd914c2c41/report.json`.

- TP=4, eager execution, context limit 2048, prefix caching disabled.
- Six serialized raw-text requests, 16 generated tokens each, temperature zero.
- Model weights remained frozen; baseline/candidate order alternated AB/BA
  across five timing pairs.
- Adapter installed on 129 normalization modules per rank.
- Candidate path was exercised. Unsupported shapes used the original method
  and recorded structured fallback counters.
- Initial before/after greedy token IDs matched exactly. Returned generated-token
  logprob maximum difference was 0.0. All repeated timing trials passed output
  regression checks.
- Median **paired** end-to-end speedup: **0.9558x**.
- One-sided 99% lower bound: **0.8571x**.
- Baseline timing CV: **12.06%**, exceeding the 10% gate.
- `deployment_approved: false`.

The ratio of the two marginal median latencies was 1.0536x, but that is **not**
the paired estimator used by the gate. It is not evidence of an approved
5.4% acceleration.

Only about 0.73% of wrapped normalization calls entered the candidate path in
the initial warmup/comparison counters. Most decode calls use residual-present
row-1 normalization, which had no accepted replacement. Coverage and adapter
overhead therefore matter more than isolated best-shape speedups.

### Report-unit erratum

The first inference report mislabeled second-valued timing arrays as `*_us`.
Its canonical `trials.baseline_sec` and `trials.candidate_sec` were correct;
speedup ratios and the rejection decision were unaffected.

The original evidence was preserved. An explicit, append-only correction is
stored at `results/20261104T123058Z-7d300f16d100/report.json`. It converts those
arrays to microseconds and identifies the paired estimator. This correction
is post-processing, not a new inference run. Current code converts seconds
before producing `*_us` fields, with a regression test.

## Reproduce on the existing machine

From the deployed project directory:

```bash
export EVOLITH_IMAGE=sha256:7a0f0fdd2771464b6976625c2b2d5dd46f566aa00fbc53eceab86ef50883da90
export EVOLITH_MODEL=/data/models/Qwen3.5-27B
export EVOLITH_GPUS=4

bash scripts/container.sh evolve \
  --model-path /models/qwen --output /results \
  --rows 1,4,16,64 --rounds 19 --iterations 128 --seed 2027
```

Use the resulting manifest path, not a manifest from a different source/runtime:

```bash
export EVOLITH_GPUS=0,1,2,3
export EVOLITH_MEMORY=192g
export EVOLITH_CPUS=24
bash scripts/container.sh verify-model \
  --model-path /models/qwen \
  --manifest /results/20261104T120748Z-7c218794634f/manifest.json \
  --output /results --tensor-parallel 4 --max-tokens 16 \
  --proposals /results/next-proposals.json
```

Then evaluate model-generated candidates:

```bash
export EVOLITH_GPUS=4
bash scripts/container.sh evolve \
  --model-path /models/qwen --output /results \
  --proposals /results/next-proposals.json \
  --rows 1,4,16,64 --rounds 19 --iterations 128 --seed 2028
```

Measurements can legitimately select no winners. Review raw samples, coverage
and the end-to-end gate before drawing performance conclusions.
